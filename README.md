# Распознавание дорожных знаков свёрточной нейронной сетью (GTSRB)

Проект эксплуатационной практики (09.03.03 «Прикладная информатика», профиль «Искусственный интеллект и анализ данных»,
Московский университет имени С.Ю. Витте, кафедра информационных систем).

## Задача

Классифицировать изображение дорожного знака по 43 классам. Распознавание знаков — одна из подсистем
систем помощи водителю (ADAS), беспилотного транспорта и мобильных роботов: по нему система узнаёт
ограничение скорости, запреты и предупреждения об опасностях.

## Данные

[German Traffic Sign Recognition Benchmark (GTSRB)](https://benchmark.ini.rub.de/gtsrb_news.html) —
открытый набор изображений, которые Институт нейроинформатики Рурского университета (Бохум) собрал из видеозаписей
камеры автомобиля на дорогах Германии. Набор использовался в соревновании IJCNN 2011.

* 43 класса, 39 209 изображений в обучающей части и 12 630 в тестовой;
* размеры изображений от ~25×25 до ~250×250 пикселей, разное освещение, размытие, частичные перекрытия;
* обучающая часть состоит из «треков» — серий примерно по 30 кадров одного физического знака.

Набор скачивается автоматически при запуске блокнота (`torchvision.datasets.GTSRB`) в папку `data/`.

## Метод

Свёрточная нейросеть на PyTorch: свёрточные блоки `Conv 3×3 → [BatchNorm] → активация → MaxPool 2×2`
и полносвязный классификатор. Проведены эксперименты:

1. базовая модель (ReLU, без регуляризации);
2. сравнение функций активации ReLU / tanh / сигмоида;
3. BatchNorm, Dropout и аугментация данных;
4. скорость обучения 0.01 / 0.001 / 0.0001;
5. глубина сети (2 / 3 / 4 блока): число параметров, вычислительная сложность и время эпохи;
6. итоговая модель с косинусным расписанием скорости обучения, оценка на тестовой выборке
   (accuracy, precision, recall, F1 по классам, матрица ошибок, ROC-кривые, разбор ошибок).

Выборка для валидации выделяется из обучающей части **по трекам**, чтобы кадры одного знака
не попадали одновременно в обучение и в проверку.

## Структура репозитория

```
├── notebooks/
│   └── gtsrb_traffic_signs.ipynb   # основной блокнот: анализ данных, обучение, эксперименты, оценка
├── src/
│   ├── config.py                   # пути, гиперпараметры, названия классов
│   ├── data.py                     # загрузка, разбиение, предобработка, аугментация
│   ├── models.py                   # архитектура CNN, расчёт параметров и операций по слоям
│   ├── train.py                    # обучение, оценка, запуск экспериментов
│   └── plots.py                    # графики для отчёта
├── data/                           # сюда скачивается GTSRB (в репозиторий не загружается)
├── results/
│   ├── figures/                    # графики
│   ├── experiments/                # история обучения каждого эксперимента (JSON)
│   └── *.csv, *.json, final_model.pt
```

## Запуск

### Google Colab (рекомендуется)

1. Открыть блокнот: `https://colab.research.google.com/github/<логин>/gtsrb-traffic-signs/blob/main/notebooks/gtsrb_traffic_signs.ipynb`
2. «Среда выполнения» → «Сменить среду выполнения» → GPU (T4).
3. В первой ячейке указать адрес репозитория в `REPO_URL`.
4. «Среда выполнения» → «Выполнить все». Полный прогон занимает примерно 30–40 минут на T4.

### Локально

```bash
git clone https://github.com/<логин>/gtsrb-traffic-signs.git
cd gtsrb-traffic-signs
pip install -r requirements.txt
jupyter notebook notebooks/gtsrb_traffic_signs.ipynb
```

## Воспроизводимость

Зерно генераторов случайных чисел зафиксировано (`SEED = 42` в `src/config.py`) для Python, NumPy, PyTorch
и загрузчиков данных; включён детерминированный режим cuDNN. Повторный запуск на той же видеокарте даёт те же
результаты; на другом оборудовании возможны отличия в последних знаках.
